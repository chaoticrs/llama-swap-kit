# D:\LocalAI (project root)

Local multi-model AI inference stack: one OpenAI-compatible endpoint (`http://127.0.0.1:8080`)
in front of native C++ backends that are started on demand and unloaded when idle or when
another model needs the memory. Built on an RTX 3050 Laptop (4 GB VRAM) + 16 GB RAM, but sizes itself to
whatever Windows x64 PC it runs on: setup picks CUDA (NVIDIA), Vulkan (AMD/Intel with 3+ GB VRAM) or CPU
builds, and every start re-detects VRAM/RAM and regenerates the config for this folder's location.

## New PC (Windows 10/11 x64; no Python, CUDA toolkit or admin rights needed)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1     # downloads backends for this GPU, sizes pools
powershell -ExecutionPolicy Bypass -File start.ps1             # http://127.0.0.1:8080, UI at /ui
```
A `registry.json` copied from another PC is fine: models whose files are missing are skipped with a warning.

## For layers built on top
This folder is the **inference brick** of a larger local harness (MCP tools, voice daemon, overlays). Other
layers talk to it only through `CONTRACT.md`: an OpenAI-compatible API addressed by **roles** (`agent`,
`chat`, `tts`, `stt`, `image`, ...) instead of model ids. Swap a model with `.\manage.ps1 role agent <model>`;
verify with `.\manage.ps1 check` (with the stack running) after any change.

| Item | What it is |
|---|---|
| `start.ps1` | Runs `manage.py detect` (re-sizes pools to this PC, regenerates config), then starts llama-swap with `config/llama-swap.yaml`; sets PATH to `bin/cuda`, points audio.cpp at `bin/espeak-ng`, and keeps uv/HF caches inside this folder. Ctrl+C stops everything. |
| `CONTRACT.md` | The public interface other layers may rely on (address, roles, endpoints, timing, errors). Everything else is internal. |
| `.gitignore` | Git tracks source, docs and the registry; binaries, weights, caches and generated config are re-creatable and ignored. |
| `manage.ps1` | Runs `scripts/manage.py` with uv's own Python (`.\manage.ps1 list`, `add <repo>`, `detect`, ...), so no system Python is needed. |
| `bin/` | Backend executables (llama.cpp, stable-diffusion.cpp, whisper.cpp, audio.cpp, llama-swap, uv) in the CUDA, Vulkan or CPU build, plus the shared CUDA runtime (CUDA build only). Rebuilt by `scripts/setup.ps1`. |
| `models/` | Model weights by kind, plus `registry.json`: the single source of truth for which models are served and how. |
| `config/` | Generated by `scripts/manage.py` from the registry. Do not edit by hand. |
| `scripts/` | `setup.ps1` (detect GPU, download matching binaries, size pools), `manage.py` (inspect/add/remove models, detect hardware, render config). |
| `workers/` | Python HTTP wrappers for models no native backend supports (one uv project each) + `_template`. |
| `tools/` | Created on demand by `manage.py`: llama.cpp source + venv for HF->GGUF conversion, uv-managed Python. |
| `.uv-cache/` | Created on demand: uv's shared package cache (hardlinked into every worker venv). |
| `_downloads/` | Release zips and setup logs. Safe to delete; `setup.ps1` re-downloads what it needs. |
| `_trash/` | Optional local scratch for files you mean to delete later. Not used by anything; ignored by git. |

Request flow: client -> llama-swap (routes by the `model` field, loads/evicts by VRAM/RAM
"capacity" pools) -> backend process on a local port.

## Using it (PowerShell)

In Windows PowerShell `curl` is an alias for `Invoke-WebRequest`, and the real `curl.exe` gets JSON quotes
stripped, so use `Invoke-RestMethod`:

```powershell
$api = 'http://127.0.0.1:8080'
# chat
(Invoke-RestMethod "$api/v1/chat/completions" -Method Post -ContentType 'application/json' -Body '{"model":"gemma-4-e4b","messages":[{"role":"user","content":"Hello"}]}').choices[0].message.content
# text to speech -> hello.wav  (voice picks the language: af_heart US English, bf_emma UK, hf_alpha Hindi ...)
Invoke-RestMethod "$api/v1/audio/speech" -Method Post -ContentType 'application/json' -Body '{"model":"kokoro","input":"Hello there","voice":"af_heart"}' -OutFile hello.wav
# speech to text (WAV input)
curl.exe -s "$api/v1/audio/transcriptions" -F model=whisper-small -F file=@hello.wav
```

Model ids come from `.\manage.ps1 list`. Any OpenAI-compatible app can use `http://127.0.0.1:8080/v1`.

Remark: binaries and model weights are never committed (see `.gitignore`); everything under `bin/` is reproducible with
`powershell -ExecutionPolicy Bypass -File scripts\setup.ps1`.
