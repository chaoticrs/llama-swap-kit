# config/audiocpp/

Generated `<id>.json` server configs, one per audio.cpp model in the registry (fixed port from 5700 up,
`backend` cpu/cuda, model family/task/path, `model_spec_override` -> `bin/audiocpp/model_specs`).
Removed by `manage.py remove <id>`. Do not edit; they are rewritten on every render.

- `kokoro.json`: Kokoro 82M TTS on CPU, port 5700.
